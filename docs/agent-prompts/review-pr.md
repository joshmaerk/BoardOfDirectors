# Review Prompt Template

Read AGENTS.md, docs/quality-gates.md and the relevant spec files for the changed area.

Check the change for scope, unrelated refactoring, Streamlit-only constraints, test coverage, validation evidence and runtime impact.

Do not rewrite the change unless explicitly asked.

Return a short review with:

1. Required fixes.
2. Optional improvements.
3. Missing tests or validation.
4. Minimal next steps.
